# Recordings Directory

This directory is used to store screenshots and video recordings from the TrafficVision application.

## Contents

- **Screenshots**: PNG/JPG images captured from the visualization
- **Videos**: MP4/AVI video recordings of traffic simulations
- **Logs**: Optional detection logs and analytics data

## Usage

Screenshots and recordings will be automatically saved here when you use the recording features (to be implemented in future versions).

## File Naming Convention

Recommended naming format:
```
YYYY-MM-DD_HH-MM-SS_description.ext

Examples:
2025-01-15_14-30-00_traffic_analysis.png
2025-01-15_14-35-00_vehicle_detection.mp4
```

## Note

This directory is included in `.gitignore` to prevent large media files from being committed to the repository. Only this README file will be tracked by Git.
